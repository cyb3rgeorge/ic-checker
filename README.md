Ever wondered what information is in a Malaysian identity card (IC) number? 
Enter any IC number and find out! 

The Open Source Malaysian IC Checker (OSMICC) displays the sex, date of birth, and place of birth encoded in a Malaysian IC.
Everything runs locally so I'm not stealing and I _can't_ steal/sell your personal information.

To use it, 
1. visit https://cyb3rgeorge.github.io/ic-checker/, or
2. download this repo and open index.html
